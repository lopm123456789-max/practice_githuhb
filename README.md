# GitHub 연습장 (연습허브)

팀장·동료의 업무 요청을 받아 GitHub 협업 흐름을 직접 처리해 보는 **모의 연습 사이트**임.
실제 GitHub와 연결되지 않으며, 진행 상황은 내 브라우저에만 저장됨.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 연습허브: 웹 사이트 / VS Code / 데스크톱 앱 3가지 모드 (클릭 방식) |
| `git-terminal.html` | Git 명령어 연습장 (터미널 입력 방식) |

## 연습허브 3가지 모드

- **웹 사이트**: 레포 생성, 협업자 초대, 이슈, 브랜치, PR, 리뷰, 머지, 브랜치 보호, 릴리즈
- **VS Code**: 클론, 상태바 브랜치 생성, 파일 편집·저장, 스테이징(+), 커밋, Publish Branch, Pull
- **데스크톱 앱**: 클론, New branch, Open in editor, 체크박스 커밋, Publish/Push/Pull origin, Create Pull Request

세 모드는 같은 저장소를 공유함. VS Code에서 Push한 브랜치는 웹 모드에서 PR로 올릴 수 있음.
각 모드는 기본 요청을 마치면 무작위 실전 요청이 계속 나옴.

## 사용 방법

- 파일을 내려받아 `index.html`을 브라우저로 열면 바로 실행됨 (설치 불필요)
- 또는 저장소 Settings → Pages → Branch 지정 후 웹 주소로 접속
